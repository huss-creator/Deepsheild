{# ==================== HOW IT WORKS ==================== #}

How DeepShield Works

A three-step forensic pipeline that combines face detection, multi-model AI analysis, and ensemble decision logic.

1

Upload Image

Upload a JPG or PNG portrait photo (max 10 MB). The system validates the file, generates a SHA-256 fingerprint, and detects a human face using OpenCV.

2

AI Analysis

Five independent AI models analyse the detected face simultaneously. Each model returns its own prediction label and confidence score.

3

Forensic Report

A weighted ensemble decision combines all model votes. View a full forensic report with per-model results, confidence visualization, and Grad-CAM heatmaps.

{# ==================== ALGORITHMS ==================== #}

Forensic Algorithms

Eight classical checks run on the whole file. They are indicators, not proof, and each one is shown with its own details.

1. Error Level Analysis
Re-compresses the file and shows regions that compress differently from the rest.
2. Frequency analysis
Looks for unusual patterns in the image spectrum left by generators.
3. Noise analysis
Checks whether the sensor noise is consistent across the picture.
4. Copy-move detection
Finds regions that were cloned from another part of the same image.
5. Face boundary
Examines the edge of the face for blending seams.
6. Resampling
Detects traces of resizing or rotation of a pasted region.
7. C2PA credentials
Reads content credentials if the file carries them.
8. EXIF metadata
Reads camera and editing-software fields; missing data is not proof of anything.
