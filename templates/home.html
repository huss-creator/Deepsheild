{# ==================== HOW IT WORKS ==================== #}

How DeepShield Works

A three-step forensic pipeline that combines face detection, multi-model AI analysis, and ensemble decision logic.

1

Upload Image

Upload a JPG or PNG portrait photo (up to {{ max_mb }} MB). The system validates the file, generates a SHA-256 fingerprint, and detects a face with OpenCV.

2

AI Analysis

Up to five AI models analyze the detected face. Each available model returns a label and raw, uncalibrated score—not a probability.

3

Forensic Report

The system combines available model outputs into an overall assessment. The report separates that assessment from supporting forensic indicators and includes explanation maps when available.

{# ==================== MODELS ==================== #}

AI Models

Five independent detectors look at the cropped face. Each one is trained for a specific kind of manipulation, so the result shows which models ran and what each one said, not one hidden number.

SDXL Detector

AI-generated images

Priority model. Specialist for fully AI-generated faces (diffusion generators). Its result counts double in the combined score.

XceptionNet

Face-swap + AI

Depthwise-separable CNN, sensitive to blending seams and texture artefacts.

EfficientNet-B4

Compound-scaled CNN that picks up fine texture artefacts.

ViT-B/16

Face-swap + AI

Vision Transformer that looks at global relationships between image patches.

FFT/DCT + SVM

Classical frequency features with an SVM classifier.

{# ==================== ALGORITHMS ==================== #}

Forensic Algorithms

Eight classical checks run on the whole file. They are indicators, not proof, and each one is shown with its own details.

1. Error Level Analysis
Re-compresses the file and shows regions that compress differently from the rest.
2. Frequency analysis
Looks for unusual patterns in the image spectrum left by generators.
3. Noise analysis
Checks whether the sensor noise is consistent across the picture.
4. Copy-move detection
Finds regions that were cloned from another part of the same image.
5. Face boundary
Examines the edge of the face for blending seams.
6. Resampling
Detects traces of resizing or rotation of a pasted region.
7. C2PA credentials
Reads content credentials if the file carries them.
8. EXIF metadata
Reads camera and editing-software fields; missing data is not proof of anything.
